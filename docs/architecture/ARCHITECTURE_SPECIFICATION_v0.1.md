# ACPA Architecture Specification v0.1

**Status:** LOCKED / SOURCE OF TRUTH  
**Artifact:** RIDZ-RC-ACP-A01  
**Evidence:** 19 reference videos

## Purpose
Create a reusable, vendor-agnostic architecture for real-client AI content production experiments.

## Layers
### L1 — Asset Intelligence
Captures asset identity, readiness, constraints and reference relationships.

### L2 — Content & Production Orchestration
Selects content family and reference pattern; constructs production grammar, scene architecture, asset mapping, visual direction, copy/CTA and constraints.

### L3 — Execution Compiler
Translates canonical production intent into engine-specific executable JSON through explicit capability checks and adapters.

## Provisional production grammar
ATTENTION → PRODUCT → HUMAN/CONTEXT → PROOF/DEMONSTRATION → BENEFIT/CLAIM → ACTION → BRAND
