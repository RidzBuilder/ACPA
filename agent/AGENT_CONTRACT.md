# ACPA Agent Contract

## Input
Asset references, approved brief when available, client/reference evidence, constraints and target output.

## Processing
L1 Asset Intelligence → L2 Content & Production Orchestration → L3 Execution Compiler.

## Output
Canonical ProductionPlan and, after capability/adapter resolution, ExecutionPackage containing engine-specific JSON.

## Non-goals
No silent invention of unsupported capabilities, no autonomous claim approval, no assumption that one client pattern is universal, and no silent mutation of locked architecture.
